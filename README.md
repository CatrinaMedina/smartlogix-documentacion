# SmartLogix — Documentación del Proyecto

## Descripción del proyecto

SmartLogix es un proyecto de software orientado al monitoreo de infraestructuras. Este repositorio centraliza la documentación técnica, los informes y los materiales de presentación relacionados con el proyecto.

## Contenido de la documentación

La carpeta `docs/` contiene los siguientes documentos:

| Archivo                                   | Descripción                                                           |
| ----------------------------------------- | --------------------------------------------------------------------- |
| `SmartLogix.pptx`                         | Presentación general del proyecto SmartLogix.                         |
| `SmartLogix_Parcial1_Informe.pdf`         | Informe correspondiente a la primera evaluación parcial del proyecto. |
| `SmartLogix_Parcial3_Informe.pdf`         | Informe correspondiente a la tercera evaluación parcial del proyecto. |
| `SmartLogix_InformeSonarqube.pdf`         | Informe de análisis de calidad del código mediante SonarQube.         |
| `Documento_Swagger_PostmanCollection.pdf` | Documentación relacionada con la API y la colección de Postman.       |

## Estructura del repositorio

```text
smartlogix-documentacion/
├── docs/
│   ├── Documento_Swagger_PostmanCollection.pdf
│   ├── SmartLogix.pptx
│   ├── SmartLogix_InformeSonarqube.pdf
│   ├── SmartLogix_Parcial1_Informe.pdf
│   └── SmartLogix_Parcial3_Informe.pdf
└── README.md
```

## Objetivo del repositorio

El objetivo de este repositorio es mantener organizada y accesible la documentación de SmartLogix, facilitando su consulta, mantenimiento y utilización como referencia durante el desarrollo del proyecto.

## Repositorios relacionados

## Herramientas y tecnologías

La documentación del proyecto hace referencia a herramientas y tecnologías como Spring Boot, Swagger, Postman y SonarQube.
